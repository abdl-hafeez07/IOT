HISTORICAL DATASET

This project does not require a manually supplied dataset.

Run:

python data/download_historical.py

It retrieves the historical data directly from the Open-Meteo Historical Weather API.

Period:
2023-01-01 to 2025-12-31

Location:
Kochi
Latitude: 9.93
Longitude: 76.27

Required columns:
temperature
humidity
precipitation
cloud_cover
wind_speed
surface_pressure
weather_code

The script creates:
data/historical_weather.csv

# Q4 - CoAP-Based Weather Monitoring and Decision Tree Classification

## Objective

Develop a CoAP-based weather monitoring and classification system for Kochi.

Flow:

Open-Meteo Weather API -> CoAP Server -> CoAP Client -> Dashboard -> Decision Tree Classification

## Live Parameters

- Temperature
- Relative Humidity
- Precipitation
- Cloud Cover
- Wind Speed
- Surface Pressure

Live API:

https://api.open-meteo.com/v1/forecast?latitude=9.93&longitude=76.27&current=temperature_2m,relative_humidity_2m,precipitation,cloud_cover,wind_speed_10m,surface_pressure

## Historical Dataset

The project retrieves historical hourly weather data from:

https://archive-api.open-meteo.com/v1/archive?latitude=9.93&longitude=76.27&start_date=2023-01-01&end_date=2025-12-31&hourly=temperature_2m,relative_humidity_2m,precipitation,cloud_cover,wind_speed_10m,surface_pressure,weather_code

The historical data covers Kochi from 2023-01-01 to 2025-12-31.

The required features are:
- temperature
- humidity
- precipitation
- cloud_cover
- wind_speed
- surface_pressure

The target weather_class is derived from weather_code.

## Weather Code Mapping

| weather_code | weather_class |
|---|---|
| 0, 1 | Clear |
| 2, 3 | Cloudy |
| 51, 53, 55 | Drizzle |
| 61, 63, 65 | Rain |

Codes outside these requested groups are excluded from model training.

## Step 1 - Install Python

Recommended: Python 3.10 or 3.11.

Check:

python --version

## Step 2 - Create virtual environment

Windows:

python -m venv venv
venv\Scripts\activate

Linux/macOS:

python3 -m venv venv
source venv/bin/activate

## Step 3 - Install packages

pip install -r requirements.txt

## Step 4 - Download historical weather data

Run:

python data/download_historical.py

This retrieves the specified historical Open-Meteo data and creates:

data/historical_weather.csv

No manual CSV download is required.

## Step 5 - Train Decision Tree

Run:

python model/train_model.py

The program:
1. Reads historical_weather.csv.
2. Converts weather_code into weather_class.
3. Keeps only the four requested classes.
4. Uses the six weather features as inputs.
5. Splits data into training and testing sets.
6. Trains a DecisionTreeClassifier.
7. Prints accuracy and classification report.
8. Saves the model as:

model/weather_decision_tree.joblib

## Step 6 - Start CoAP Server

Open Terminal 1:

python coap/coap_server.py

The server listens at:

coap://127.0.0.1:5683/weather

When the client sends GET /weather, the server requests current Kochi weather from Open-Meteo and returns JSON.

## Step 7 - Test CoAP Client

Open Terminal 2:

python coap/coap_client.py

It sends a CoAP GET request and displays:
- Temperature
- Relative Humidity
- Precipitation
- Cloud Cover
- Wind Speed
- Surface Pressure

## Step 8 - Start Dashboard

Open Terminal 3:

python dashboard/app.py

Open:

http://127.0.0.1:5000

The dashboard obtains current data through the CoAP server/client flow and then sends the six values to the trained Decision Tree model.

## Dashboard

The dashboard displays:
- Kochi location
- Temperature
- Relative Humidity
- Precipitation
- Cloud Cover
- Wind Speed
- Surface Pressure
- Predicted weather class
- API update time

The dashboard refreshes every 60 seconds.

## Troubleshooting

### Historical CSV missing

Run:

python data/download_historical.py

### Model missing

Run:

python model/train_model.py

### CoAP client connection error

Start the server first:

python coap/coap_server.py

### API error

Check internet access and retry.

### Port 5683 already in use

Change COAP_PORT in both coap_server.py and coap_client.py to the same free port.

## Important Note

The question specifies the weather classes Clear, Cloudy, Drizzle and Rain. Therefore the training script uses exactly the requested weather-code mapping and excludes other weather codes such as snow, freezing rain, fog, thunderstorms, etc.

The predicted class is the Decision Tree model's classification based on the historical Open-Meteo data. It is not a direct textual weather description from the live API.
